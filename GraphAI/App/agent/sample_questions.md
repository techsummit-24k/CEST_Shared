# Good research questions

1. Which genes are associated with Type 2 Diabetes Mellitus, and what evidence scores and sources support them?

2. Show a graph path from Imatinib to Chronic Myeloid Leukemia.

3. Which drugs target proteins linked to genes associated with Breast Cancer, excluding drugs already recorded as treating Breast Cancer?

4. Which pathways connect genes associated with Type 2 Diabetes Mellitus?

5. Show the evidence sources for the relationship between ABL1 and Chronic Myeloid Leukemia.
